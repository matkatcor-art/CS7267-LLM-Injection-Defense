# B1-Optuna Implementation Plan

**Goal:** A `tfidf-optuna` B1 variant whose features and `C` are chosen by a 100-trial Optuna
study on family folds of train_pool train, evaluated once through the unchanged harness.

**Spec:** `docs/superpowers/specs/2026-11-18-b1-optuna-design.md`. Its decisions, decision rule
and anti-goals bind every task.

**Branch:** `phase4/b1-optuna`, from `main` at `75d33a2`.

## Global constraints

- `src/models/tfidf.py`, `src/data/dataset.py` and `dataset.parquet` are not edited.
- Trials read only train_pool train, via `dataset.load("fit", ...)` and `check_fit_rows`.
- The sampler seed (7267), fold seed (7267), `k=5` and the 100-trial budget are fixed before the
  run and never changed after seeing a number.

## Tasks

### Task 1: `family_folds` (shared with B1-famcv)
- [x] Implement Task 1 of `docs/superpowers/plans/2026-11-08-b1-family-cv.md` as written:
  `src/eval/family_cv.py` and `tests/test_family_cv.py`.
- [x] Check on the real data: train + val gives BIPIA 486/486 in folds 0–3 and 485/485 in fold

  400–401 BIPIA pairs and 215–220 PoisonedRAG attacks per fold.

### Task 2: the configurable detector and search space

### Task 3: objective, guard and study
- [x] `check_fit_rows` raises `HoldoutError` on any val, test, MCPTox or MSB row

- [x] `run_study` with `TPESampler(seed=7267)`: a fixed seed gives the same best trial

### Task 4: outputs and CLI
- [x] `save_study` writes `best_params.json`, `trials.csv`, `folds.csv`, `history.png`,
  `importance.png` under `report/phase4/b1_optuna/`.
- [x] `main` refits the best settings on train, evaluates once, writes
  `report/baselines/b1_tfidf_lr_optuna.csv`, and logs to MLflow (one run plus nested trials)
  when a tracking URI is set (`test_main_writes_the_study_and_the_report`).
- [x] `make b1-optuna`; `optuna` and `matplotlib` added to the main dependencies.
- [x] One progress line per finished trial (state, score, best so far, duration); `progress=False` turns it off.
- [x] `trials.csv` is a `trials_table`: one row per trial, parameters without the `params_`
  prefix, `none` for a `None` value of a parameter sampled every trial (`max_features`,
  `class_weight`), empty for a parameter the trial did not use.
- [x] A failed MLflow upload no longer loses a finished study: the files are written first, and
  `make b1-optuna ARGS=--log-only` uploads them later. It refits the best settings to recompute
  the threshold (seconds) instead of re-running the study.

### Task 5: run and decide
- [x] `make b1-optuna` (100 trials, 2026-11-18, about 55 minutes). Outputs committed:
  `report/baselines/b1_tfidf_lr_optuna.csv` and `report/phase4/b1_optuna/`. All 100 trials
  completed; the pruner stopped none.
- [x] Decision rule: **better than B1.** Test `all` AUROC 0.922 [0.907, 0.935] is above B1's upper
  bound (0.902 [0.886, 0.917]); `source=bipia` AUROC 0.862 vs 0.849. Best trial #93, mean CV
  AUROC 0.9215: word 1–3 + `char` 2–4-grams, `C` 6.38, `min_df` 1, 200k features per vectorizer,
  `sublinear_tf`, `class_weight="balanced"`. Holdouts, reported only: MCPTox AUROC 0.767 (B1
  0.675), TPR at 5% FPR 0.274 (B1 0.225).
- [x] **Upload to MLflow** (2026-11-19). The upload at the end of the run had failed because the
  Neon `production` branch had lost its compute endpoint. Once a compute was back, `make
  b1-optuna ARGS=--log-only` logged one `tfidf-optuna` run with 100 nested trial runs; its
  threshold (0.624534), metrics and artifacts match the committed files.
